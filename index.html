CONFIGURATION HELP

配置帮助

按以下步骤创建图片接口密钥，并选择一种方式打开图片处理工作台。

1

创建 APIKEY

在 API 平台创建 APIKEY，分组选择“image”。

APIKEY 的名称必须是：image（小写）
2

选择一种打开方式

完成步骤 1 后，可以直接从 API 平台进入，也可以访问独立的图片处理站点。

方式 1

从 API 平台直接打开

通过 API 平台导航菜单直接打开“图片处理”。

方式 2

访问独立图片处理站点
